# Cloudflare challenge: build the next Git platform

Source: https://blog.cloudflare.com/next-git-platform-on-cloudflare/ · submit at https://www.cloudflare.com/git-competition

- **Deadline:** 2026-10-14. Three finalists announced 2026-10-16, they present at Cloudflare Connect
  in San Francisco (travel for up to two people). First place: 25,000 USD Cloudflare credits.
- **Brief:** a Git platform for a world where agents are the main developers. Rethink repositories,
  branches, pull requests, worktrees, code review and merge conflicts. Not GitHub with agents on top.
  Minimum bar: multiple agents working on changes concurrently.
- **Must use:** Cloudflare Workers and Artifacts (open beta, Workers Paid plan).
- **Submit:** 5–10 minute demo video, source under MIT/Apache/BSD, instructions to run it.
